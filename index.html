Need to start again?

Made a mistake during installation? You can restart the guide yourself. You do not need to contact the seller.

Safe retry: Check your Supabase project and Netlify environment variables, correct the failed step, then redeploy and run verification again. The included schema.sql is designed to be re-run for missing objects; it is not a full migration or repair tool. Do not delete your database or project to fix an ordinary setup error. If you need a completely clean database, create a new empty Supabase project under your own account and run schema.sql there, then update your Netlify environment variables and redeploy. Existing financial data will not be transferred automatically. Never put a Supabase secret key in this page.
